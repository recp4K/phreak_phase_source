01 // SUMMING BUS ROUTING

Freak Phase V2 is a 4-in / 2-out Summing Bus plugin. Route your Kick to Input 1/2 (Track A) and Bass to Input 3/4 (Track B). The plugin aligns them and outputs a single summed low-end signal.

02 // GCC-PHAT TIME-DELAY ESTIMATION

Phase cancellation is solved using instantaneous Generalized Cross-Correlation with Phase Transform normalization, identifying the optimal sub-sample delay offset in an FFT pass.

03 // TIME-BENDING TPT ALL-PASS CASCADE

Instead of standard linear delays that cause smearing across harmonics, we employ 2-stage Topology-Preserving Transform (TPT) All-Pass filters that rotate low frequencies dynamically without altering the upper transient punch.
